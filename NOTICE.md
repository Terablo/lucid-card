## IBM Plex Mono — `plex-mono-latin-400.woff2` and three siblings

Copyright © 2017 IBM Corp., **with Reserved Font Name "Plex"**. Licensed under
the SIL Open Font License, Version 1.1 (https://openfontlicense.org). Licence
text: `plex-mono.woff2.LICENSE.txt`.

Redistributed as built and served by Google Fonts: weights 400 and 500, each
cut into Latin and Latin Extended subsets, in WOFF2. Not further modified here.

**The reserved name is why the CSS family is `LucidNexus Mono`.** OFL clause 3
forbids a Modified Version from using a Reserved Font Name as "the primary font
name as presented to the users", and a subset is a modified version. The files
are Google's byte for byte and their internal names are untouched, so this
project presents no font to a user under the name Plex. The prefix also does
the same job it does for Inter and Sora — keeping a differently-versioned copy
on the viewer's machine from winning.
